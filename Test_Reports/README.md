# 📊 Test Reports

This folder contains test execution summaries and result logs for completed QA cycles.  
Reports follow the format used in Agile/Scrum sprint-based environments.

---

## 📋 Index

| File | Module | Sprint | Pass Rate |
|------|--------|--------|-----------|
| `Report_Login_Sprint01.md` | Login | Sprint 01 | 87.5% |

---

## 📐 Report Format

| Field | Description |
|-------|-------------|
| **Sprint / Cycle** | Testing period |
| **Scope** | Modules and features tested |
| **Total Test Cases** | Number executed |
| **Pass / Fail / Blocked** | Result breakdown |
| **Pass Rate** | Percentage of passing tests |
| **Critical Bugs Found** | High severity issues |
| **Notes** | Observations and recommendations |
