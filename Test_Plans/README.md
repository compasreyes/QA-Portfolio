## 📐 Test Plan Format

Each test plan includes:

- **Objective** — What the plan aims to validate
- **Scope** — Features included and excluded
- **Test Types** — Functional, Regression, Smoke, UAT, etc.
- **Entry & Exit Criteria** — Conditions to start and finish testing
- **Risks** — Potential blockers or issues
- **Deliverables** — Expected outputs (reports, sign-off, etc.)
